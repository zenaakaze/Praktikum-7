# LAPORAN PRAKTIKUM 7
## Pemrograman Web – PHP

### 1. Tujuan Praktikum
Praktikum ini bertujuan untuk mempelajari dasar-dasar pemrograman PHP, penggunaan variabel, operator, percabangan, array, perulangan, fungsi, serta pengolahan data menggunakan form GET dan POST.

### 2. Alat dan Bahan
- Laptop atau komputer
- Visual Studio Code
- XAMPP
- Web Browser
- Bahasa pemrograman PHP

### 3. Langkah Menjalankan Program
1. Membuka aplikasi XAMPP.
2. Mengaktifkan Apache melalui XAMPP Control Panel.
3. Membuat folder `Lab7Web_PHP` di dalam direktori `htdocs`.
4. Membuat file PHP sesuai latihan praktikum.
5. Menjalankan program melalui browser menggunakan alamat `http://localhost/Lab7Web_PHP/`.

### 4. Struktur Folder
```text
Lab7Web_PHP/
├── index.php
├── latihan2.php
├── latihan3.php
├── latihan4.php
├── cari.php
├── latihan6.php
├── latihan7.php
├── mahasiswa.php
└── README.md
```

### 5. Penjelasan Program
- **index.php**: Menampilkan halaman awal dan informasi waktu server.
- **latihan2.php**: Menghitung nilai akhir mahasiswa dan menentukan predikat.
- **latihan3.php**: Menampilkan data mahasiswa menggunakan array dan foreach.
- **latihan4.php**: Menghitung harga setelah mendapatkan diskon.
- **cari.php**: Mengolah input pencarian menggunakan metode GET.
- **latihan6.php**: Mengolah data mahasiswa menggunakan metode POST.
- **latihan7.php**: Menghitung subtotal transaksi berdasarkan harga dan jumlah barang.
- **mahasiswa.php**: Formulir data mahasiswa dengan validasi input.

### 6. Pengujian Program
Pengujian dilakukan dengan memasukkan data valid dan tidak valid untuk memastikan program berjalan sesuai fungsinya.

**Contoh pengujian mahasiswa.php:**

| Pengujian | Input | Hasil yang Diharapkan |
|---|---|---|
| Valid 1 | Semua data diisi dengan benar | Data berhasil ditampilkan |
| Valid 2 | Email menggunakan format yang benar | Data diterima |
| Tidak Valid 1 | Nama dikosongkan | Muncul pesan kesalahan |
| Tidak Valid 2 | Email menggunakan format salah | Muncul pesan kesalahan |
